# Disease-mediated thermal limits in frogs
R scripts and code workflows for mechanistic ecophysiological modeling, microclimate simulations, and disease-mediated ecological niche models (ENMs) for the Panamanian golden frog.

**Authors:** Diele-Viegas et al.

**Repository Workflow Documentation**

This repository contains an end-to-end computational pipeline integrating **mechanistic ecophysiology** and **Ecological Niche Modeling (ENM)** to evaluate how pathogen infection (e.g., chytridiomycosis) and climate change interact to constrain amphibian thermal limits, distributions, and vulnerability across spatial and temporal scales.

---

## 🚀 Workflow Pipeline Overview

The analysis pipeline consists of sequential R scripts ranging from raw data processing and ecophysiological modeling to ensemble projections, spatial map generation, and final statistical analysis.

## ⚙️ Execution Guidelines

1. **Set your Working Directory:** Update the base path variable at the beginning of each script to match your local data directory structure.
2. **Run Sequentially:** Execute the scripts in numerical order (`00` to `08`), as subsequent steps rely heavily on outputs generated by earlier scripts (e.g., cleaned occurrences feed into algorithms, algorithms feed into ensembles, and ensembles feed into binarization and final stats).

---

## 📂 Expected Directory Structure

Your working directory should follow this organizational layout to ensure all relative file paths link correctly:

```text
amphibian_data/
├── 02_occ/                     # Cleaned occurrence data
├── 03_var/                  # Environmental & mechanistic raster inputs
├── 04_algorithms/           # Algorithm predictions, evaluations, and importance scores
├── 05_ensemble/             # Weighted ensemble raster outputs
├── 06_binary/               # Binary MAX_TSS thresholded maps
├── 07_spatial_analysis/     # Spatial maps 
└── 08_stats/                # Final summary tables, forest plots, and variable importance figures

```
